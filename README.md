# Gestion des employés — Application RH

## 📌 Présentation du projet

**Gestion des employés** est une application web développée avec React.js permettant de centraliser et de gérer les informations des employés d'une entreprise.

L'application offre une interface simple et intuitive pour consulter les employés, rechercher des profils, gérer les services, suivre les statistiques et enregistrer les employés favoris.

Ce projet est réalisé dans le cadre d'un mini-projet React.js.

## 🎯 Objectifs

- Organiser les informations des employés.
- Faciliter la recherche et le filtrage des employés.
- Permettre la création, la modification et la suppression des profils.
- Visualiser les statistiques par service.
- Gérer les employés favoris avec Redux.
- Pratiquer la consommation d'une API REST et la gestion globale de l'état avec Redux Toolkit.

## ✨ Fonctionnalités

### 1. Tableau de bord (Dashboard)
- Affichage du nombre total d'employés.
- Répartition des employés par service.
- Visualisation des statistiques sous forme de graphiques.
- Mise à jour des indicateurs à partir des données disponibles.

### 2. Gestion des employés
- Affichage de la liste des employés.
- Recherche par nom.
- Filtrage par service.
- Consultation des détails d'un employé.
- Ajout d'un nouvel employé.
- Modification des informations d'un employé.
- Suppression d'un employé.

### 3. Gestion des favoris
- Ajouter un employé aux favoris.
- Retirer un employé des favoris.
- Consulter la liste des employés favoris.

### 4. Formulaires
- Saisie des informations personnelles et professionnelles.
- Validation des champs obligatoires.
- Affichage des messages de confirmation et d'erreur.

### 5. Navigation
- Navigation entre les différentes pages.
- Accès à la liste et aux détails des employés.
- Pages d'ajout et de modification.
- Gestion des routes inexistantes avec une page 404.

### 6. Gestion des requêtes API
- Chargement des données.
- Gestion des états de chargement.
- Gestion des erreurs réseau.
- Opérations CRUD avec une API REST.

## 🛠️ Technologies utilisées

- **React.js** : création de l'interface utilisateur.
- **JavaScript** : logique de l'application.
- **CSS** : mise en forme et design.
- **React Router** : navigation entre les pages.
- **Redux Toolkit** : gestion de l'état global.
- **React Redux** : connexion des composants au Store.
- **Fetch API** : communication avec l'API
